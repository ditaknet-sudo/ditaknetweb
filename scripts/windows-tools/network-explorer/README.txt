DitakNet Network Explorer - Windows Standalone Edition
======================================================
Created by: DitakNet (Smart Tech & IT Monitoring)
Website: https://ditaknet.com

Description:
Deep network exploration and diagnostic tool designed for network engineers and IT technicians.
Scans local subnets, identifies active devices, measures latency, discovers open service ports
(HTTP, HTTPS, SSH, WinBox, RTSP, SMB, RDP), and produces instant JSON & CSV reports.

How to Run:
1. Double click "DitakNet-Network-Explorer.bat"
2. Follow on-screen instructions (press ENTER to use detected default subnet)
3. Results are shown in terminal and automatically saved as network-explorer-report.json and .csv

Requirements:
- Windows 10, 11 or Windows Server 2016+
- PowerShell 5.1 or later (pre-installed on Windows)
- No third-party drivers or WinPcap required
