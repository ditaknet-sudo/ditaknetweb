DitakNet LAN Scan - Standalone Windows Tool
========================================================================

Այս ծրագիրը նախատեսված է Windows օպերացիոն համակարգում (Windows 10, 11,
Windows Server) տեղային ցանցի սարքերի արագ հայտնաբերման և գույքագրման համար։

Ինչպես աշխատեցնել (How to Run):
----------------------------------
1. Կրկնակի սեղմեք (Double-click) "DitakNet-LAN-Scan.bat" ֆայլի վրա։
2. Ծրագիրը ինքնաշխատ (auto-detect) կգտնի ձեր ակտիվ ցանցային քարտը և ենթացանցը (օր. 192.168.1.0/24)։
3. Ծրագիրը կկատարի բոլոր 254 IP հասցեների արագ սքանավորում (ping sweep), կորոշի MAC հասցեները, արտադրողներին (MikroTik, Dahua, Hikvision, Synology, Intel, Cisco և այլն) և բաց պորտերը (80, 443, 554 RTSP, 22 SSH, 5833 DitakNet)։
4. Արդյունքները ավտոմատ կպահպանվեն նույն թղթապանակում՝ "lan-scan-report.csv" և "lan-scan-report.json" ֆայլերում։

DitakNet Ինտեգրում:
-------------------
Գեներացված JSON ֆայլը կարող եք ներմուծել DitakNet Monitoring Server (:5833), որպեսզի սարքերը միանգամից ավելացվեն մոնիթորինգի վահանակին։
