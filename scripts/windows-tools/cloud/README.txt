DitakNet Cloud - Standalone Windows Vault & Backup Tool
========================================================================

Այս ծրագիրը նախատեսված է տեղային ֆայլերի, փաստաթղթերի, գաղտնաբառերի և
կոնֆիգուրացիաների մասնավոր պահպանման և SHA256 հեշերով արխիվացման համար։

Ինչպես աշխատեցնել (How to Run):
----------------------------------
1. Տեղադրեք ձեր կարևոր ֆայլերը "MyVault" թղթապանակում։
2. Կրկնակի սեղմեք "DitakNet-Cloud-Sync.bat" ֆայլի վրա։
3. Ծրագիրը կհաշվարկի յուրաքանչյուր ֆայլի SHA256 կրիպտոգրաֆիկ հեշը, կստուգի ամբողջականությունը (integrity) և կստեղծի արխիվային ZIP պատճեն։
4. Արդյունքները կարող եք տեղափոխել ձեր սեփական DitakNet սերվեր (:5833)։

Կայք: https://www.ditaknet.com
