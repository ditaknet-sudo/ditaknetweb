DitakNet Port Audit & Firewall NAT Check - Windows Standalone
=============================================================
Created by: DitakNet (Smart Tech & Security Engineering)
Website: https://ditaknet.com

Description:
Fast port reachability and firewall security auditing tool.
Tests critical service ports (HTTP, HTTPS, SSH, RDP, WinBox, RTSP, SMB, SQL, VPN)
against gateways, servers, or external IP addresses, measures connection latency,
flags risky exposed services, and exports audit logs to JSON and CSV.

How to Run:
1. Double click "DitakNet-Port-Audit.bat"
2. Press ENTER to audit the local gateway, or enter any IP / hostname
3. View open service ports, connection latency, and security risk levels
4. Output automatically saved to port-audit-report.json/.csv

Requirements:
- Windows 10, Windows 11, or Windows Server
- PowerShell 5.1+ (included in Windows)
