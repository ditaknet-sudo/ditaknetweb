DitakNet CCTV Camera & RTSP Stream Probe - Windows Standalone
=============================================================
Created by: DitakNet (Smart Tech & Security Engineering)
Website: https://ditaknet.com

Description:
Automated scanner for CCTV security cameras, NVRs, and video encoders.
Detects Dahua, Hikvision, Uniview, Axis, and generic ONVIF cameras across subnets,
scans ports 554 (RTSP), 8000, 37777, 8899, generates RTSP stream test URLs, and exports
complete inventories to JSON and CSV.

How to Run:
1. Double click "DitakNet-CCTV-Probe.bat"
2. Press ENTER to scan the detected subnet or enter a custom one (e.g. 192.168.1)
3. Results display in console and save to cctv-probe-report.json/.csv

Requirements:
- Windows 10, Windows 11, or Windows Server
- PowerShell 5.1+ (built into Windows)
- No additional driver or software installation required
