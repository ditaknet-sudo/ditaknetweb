DitakNet VLAN Scan - Standalone Windows Tool
========================================================================

Այս ծրագիրը նախատեսված է Windows օպերացիոն համակարգում (Windows 10, 11,
Windows Server) VLAN հատվածների (VLAN segments), ենթացանցերի և մեկուսացման (isolation)
ստուգման համար։

Ինչպես աշխատեցնել (How to Run):
----------------------------------
1. Կրկնակի սեղմեք "DitakNet-VLAN-Scan.bat" ֆայլի վրա։
2. Ծրագիրը կստուգի ձեր համակարգչի բոլոր ցանցային ինտերֆեյսները, 802.1Q VLAN կարգավորումները և երթուղիները (routing table)։
3. Կստուգի հիմնական VLAN gateway-ների հասանելիությունը (VLAN 1 Default, VLAN 10 Servers, VLAN 20 CCTV, VLAN 30 Guest, VLAN 40 Office, VLAN 50 VoIP)։
4. Ցույց կտա, թե որ VLAN-ներն են մեկուսացված (isolated) և որոնք են հասանելի։
5. Արդյունքները կպահպանվեն "vlan-scan-report.csv" և "vlan-scan-report.json" ֆայլերում։

Կայք: https://www.ditaknet.com
