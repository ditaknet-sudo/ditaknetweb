========================================================================
DitakNet Service Watch - Standalone Windows Tool
========================================================================

Այս ծրագիրը նախատեսված է կայքերի, API-ների, ներքին սերվերների,
CCTV RTSP պորտերի և տեղային IP հասցեների անընդհատ մոնիթորինգի (uptime monitoring) համար։

Ինչպես աշխատեցնել (How to Run):
----------------------------------
1. Կրկնակի սեղմեք "DitakNet-Service-Watch.bat" ֆայլի վրա։
2. Ծրագիրը ինքնաշխատ կսկսի ստուգել կոնֆիգուրացված ծառայությունները և կցուցադրի live վիճակը (Online / Warning / Offline), latency-ն և HTTP / TCP պատասխանի կոդերը։
3. Բոլոր ստուգումների պատմությունը պահպանվում է "service-watch-log.csv" ֆայլում։
4. Ցանկության դեպքում կարող եք "services-to-watch.json" ֆայլում ավելացնել ձեր սեփական սերվերները, կայքերը կամ IP-ները։

Կայք: https://www.ditaknet.com
