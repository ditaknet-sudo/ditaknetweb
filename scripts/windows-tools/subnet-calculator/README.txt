DitakNet Subnet Calculator & CIDR Planner - Windows Standalone
==============================================================
Created by: DitakNet (Smart Tech & Network Engineering)
Website: https://ditaknet.com

Description:
Fast, offline IPv4 subnet calculator and CIDR boundary planning utility for network engineers.
Computes network addresses, subnet masks, wildcard masks, broadcast addresses, usable host ranges,
and automatically breaks down large subnets into smaller VLAN segments.

How to Run:
1. Double click "DitakNet-Subnet-Calculator.bat"
2. Enter an IP with CIDR (e.g. 192.168.10.0/24 or 172.16.0.0/20)
3. Review detailed calculation and VLAN subdivision table
4. Automatically saves report to subnet-calculator-report.json

Requirements:
- Windows 10, Windows 11, or Windows Server
- PowerShell 5.1+ (included in Windows)
