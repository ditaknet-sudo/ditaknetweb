DitakNet Bandwidth, Latency & Jitter Tester - Windows Standalone
================================================================
Created by: DitakNet (Smart Tech & Network Engineering)
Website: https://ditaknet.com

Description:
Fast network quality, link speed, packet jitter (PDV), and latency benchmark tool.
Tests network interfaces, determines physical link throughput (1 Gbps, 2.5 Gbps, 10 Gbps, Wi-Fi),
measures round-trip ping jitter and packet drop rates to gateways, switches, or Internet hosts.

How to Run:
1. Double click "DitakNet-Bandwidth-Test.bat"
2. Press ENTER to benchmark against the local gateway, or enter an IP/hostname
3. View min/avg/max latency, jitter, and link health rating
4. Automatically exports to bandwidth-test-report.json

Requirements:
- Windows 10, Windows 11, or Windows Server
- PowerShell 5.1+ (included in Windows)
